# No built-in quick preview; pair with PowerToys Peek

PowerToys Peek already gives Windows a Quick Look equivalent (Ctrl+Space in Explorer). Glance deliberately doesn't build its own spacebar previewer: it would duplicate Peek, and macOS Preview doesn't have one either. Glance is the editor you land in after previewing. Being registered as an "Open with" and default app makes Peek's "Open with default app" hand off to Glance, mirroring macOS's Quick Look → Preview flow.
