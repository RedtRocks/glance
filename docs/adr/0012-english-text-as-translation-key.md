# English text is the translation key

UI text goes through `t('English text', { placeholders })` from `src/i18n`, and other languages are JSON files mapping that English text to a translation. We chose this over named keys (`t('settings.theme.title')`) because many changes add UI at once: with named keys each one would also edit a shared English catalog, conflicting constantly, and the code would stop showing what the user reads. The cost is that rewording English text orphans its translations; `npm run i18n <lang>` drops the stale entry and adds the new one, and the app shows English until it is translated. Placeholders use a small subset of ICU MessageFormat (`{name}` and `{n, plural, …}`) so translators get the plural forms their language needs. Glance follows the Windows display language, with an override in Settings, and ships Windows' `qps-ploc` pseudo-locale for spotting text that skips translation or gets clipped.
